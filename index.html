Welcome

Playwright tests, AI projects, and a Gemini chatbot — hosted on GitHub.

Why the chatbot doesn’t run on this page

GitHub Pages only serves static HTML/CSS/JS files. The chatbot also needs a Node.js server and SQLite database to save chats and call Gemini — those cannot run on GitHub Pages. That’s why you saw a 404 before, and why the chat UI itself isn’t here.

Run the chatbot on your computer

cd chatbot
npm install
npm start

Open http://localhost:3000 and add your Gemini API key in Settings.

Run it live on the internet

Use a free host that runs Node.js, for example Render:

  • Connect your GitHub repo
  • Set Root Directory to chatbot
  • Deploy — you’ll get a URL like https://your-app.onrender.com
